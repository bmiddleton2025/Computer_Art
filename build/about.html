Purpose

The purpose of this site is to bridge a gap in STEM around morse code. Morse code is largely an unplugged activity; this site changes text to Morse code then into an image. The morse code then becomes an art piece visually and auditorily. I plan to have students write poems and have hidden meaning in their art.
