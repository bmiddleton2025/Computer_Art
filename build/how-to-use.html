Settings

Icon

To change the icons for the dots, dashes, and spaces you need to ...

  • Go to Iconify.
  • Search the icon you want.
  • Select the icon of your choosing.
  • Scroll down to where all the information is.
  • Right next to the icon name select box there is a copy button that when clicked will copy the name of the icon.
  • Back in settings, replace the icon name with your new one.

Frequency

  • Measured in hertz (Hz) - 1Hz = 1 cycle per second
  • Defines how often a phenomenon (like sound or radio waves) repeats
  • Increase or decrease the hertz value to adjust
  • Higher hertz = higher pitch

Color

  • Set color for dots, dashes, spaces, and background
  • Uses RGB (red, green, blue) values
  • Click the colored box next to the component you want to change
  • Type RGB values or drag sliders to select your color

Icons Per Row

  • Adjust the number of icons per row
  • Unlimited rows available
  • Range: 1 to 50 icons per row

Speed

  • Adjusts how long it takes for an icon to play (in seconds)
  • Higher speed = longer notes play
